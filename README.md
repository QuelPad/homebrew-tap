# QuelPad Homebrew tap

```sh
brew install quelpad/tap/quelpad
```

Installs [QuelPad](https://quelpad.com/) — the TypeScript scratchpad with databases built in — and puts the `quelpad` CLI on your `PATH`. Apple Silicon, signed and notarized.

QuelPad updates itself in-app; `brew upgrade` works too. The cask is bumped automatically within a few hours of each release.

Bugs and feedback: [QuelPad/quelpad issues](https://github.com/QuelPad/quelpad/issues).
